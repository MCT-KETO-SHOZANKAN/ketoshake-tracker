# ケトシェイク記録ノート（KETOneUP）v2

「正月リセット みんなで一緒にダイエット（仮）」の参加者が、ケトシェイクを朝・昼・夜のいつ飲んだかをワンタップで記録するスマホ向けWebツールです。

## 機能

- 最初の画面（初回のみ）：ようこそ → ご利用の前に → コースを選ぶ、の3枚
- コースの選択と変更：週末集中（第1〜3回）と1週間（第1〜2回）から選ぶ。設定からいつでも変更でき、記録は消えない
- プログラム表示：開始前は「開始まであと◯日」、期間中は「Day◯／◯」とその日の内容、最終日以降は「完走」
- 朝・昼・夜をタップで記録（もう一度タップで取り消し）
- 3杯そろったとき：紙吹雪と、励ましのメッセージ（10種類からランダム。直前と同じものは出さない）
- 体調がすぐれないとき：やめる目安と医師への相談を案内。「プログラムをやめる」（2回押しで確定）と「再開する」
- 今日のひとこと：オープンチャット投稿用の文章コピーと、画像（1080×1080）の保存
- 振り返り：記録した日数、杯数、最長の連続日数、時間帯ごとの回数、日ごとの記録
- 修了後の続けるモード：続けるコツ、完走特典の案内、商品・定期便へのリンク
- 修了証：最終日から作成できる画像（1080×1350）。ニックネームを入れられる。提出は不要
- 連続記録日数、今月の杯数、体重メモ、カレンダー、バックアップ（書き出し・読み込み）

完走の判定：コースの最終日になれば完走（記録の有無は問わない）。「やめる」を押した場合は、再開するまで完走になりません。

## 記録の保存先

記録はスマホのブラウザ内（localStorage）だけに保存し、外部には送信しません。

## 公開前に確認が必要なこと

| 項目 | 場所 | 確認先 |
| --- | --- | --- |
| 体調がすぐれないときの文言 | 「体調がすぐれないとき」画面 | 管理栄養士・法務 |
| 励ましメッセージ10種 | `CHEERS`（index.html内） | 法務 |
| 続けるコツ3項目 | 「これからも」カード | 管理栄養士・澤岡さん |
| 完走特典の内容 | 「これからも」カード | えびすチーム（現在は「オープンチャットでお知らせ」と表記） |
| 企画名（仮） | `PROGRAM_NAME`（index.html内） | 企画確定後に差し替え |
| 開催日 | `COURSES`（index.html内） | 企画確定（11/27）後に再確認 |

## 動作確認の方法

URLの末尾に `?today=2027-01-16` のように日付を付けると、その日として表示されます（確認用。記録した時刻は残りません）。

- 開始前：`?today=2027-01-10`
- 週末集中 第1回の期間中：`?today=2027-01-16`
- 週末集中 第1回の最終日：`?today=2027-01-18`

## GitHub Pagesでの公開手順

1. GitHubでリポジトリを作成し、このフォルダのファイルをアップロード
2. Settings → Pages → Branch を `main` / `/(root)` にして Save
3. 数分後に `https://<アカウント名>.github.io/<リポジトリ名>/` で公開される
