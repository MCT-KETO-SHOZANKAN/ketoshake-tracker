# ケトシェイク記録ノート（KETOneUP）

お客様がKETOneUP ケトシェイクを「朝・昼・夜」のいつ飲んだかを、ワンタップで記録するスマホ向けWebツールです。

## 機能

- 朝・昼・夜のボタンをタップして記録（もう一度タップで取り消し。今日の記録には時刻も残る）
- 3回すべて記録すると完了の演出
- 連続記録日数（ストリーク）と今月の合計杯数
- 体重メモ（1日1件）と直近30日のグラフ
- 月ごとのカレンダー表示。日付をタップすると、その日の記録を後から追加・修正できる
- ホーム画面追加の案内（iPhone / Android別。ホーム画面から開いた場合は表示しない）
- 記録のバックアップ（JSONファイルの書き出し・読み込み）

## 記録の保存先

- お客様のスマホのブラウザ内（localStorage）に保存します。サーバーには送信しません。
- 機種変更やブラウザのデータ削除で記録は消えます。引き継ぐ場合は「書き出し」→新しい端末で「読み込み」。
- iPhoneのSafariは、ホーム画面に追加していないサイトの保存データを、7日間使わないと削除する仕様があります。ホーム画面に追加すれば対象外です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | ツール本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| manifest.json | ホーム画面に追加したときのアプリ名・色・アイコンの設定 |
| icon-192.png / icon-512.png | Android用アイコン |
| apple-touch-icon.png | iPhone用アイコン |

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成（例：`ketoshake-tracker`）
2. このフォルダ内のファイルをすべてアップロード（cowork.log・README.mdは任意）
3. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<アカウント名>.github.io/ketoshake-tracker/` で公開される

## 今後の拡張案

| 段階 | 方法 | できること |
|---|---|---|
| 現在 | 端末内保存（GitHub Pages） | 無料・サーバー不要。端末をまたいだ記録共有は不可 |
| 次の段階 | LINEミニアプリ（LIFF）＋データベース | LINE IDと記録を紐付け、機種変更でも記録が残る。LINE公式アカウントから飲み忘れ通知を送れる |
| 別案 | Firebase / Supabase でログイン機能 | メールやGoogleログインで記録をクラウド保存 |
| 最終段階 | ネイティブアプリ | App Store / Google Play の審査・維持費がかかるため、効果検証後に判断 |
